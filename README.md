# Flow Translate 🌐

Современный клиент-серверный веб-сервис для машинного перевода текстов, документов, изображений и веб-страниц со встроенным персональным словарём, системой кэширования и двухфакторной аутентификацией (TOTP).

---

## 🚀 Архитектура и стек технологий

### Backend:
* **Python 3.13** + **FastAPI** — высокопроизводительный асинхронный REST API
* **PostgreSQL 16** + **SQLAlchemy 2.0 (asyncpg)** — надёжная реляционная база данных с асинхронным драйвером
* **JWT (JSON Web Tokens)** + **bcrypt** + **PyOTP / QRCode** — безопасная аутентификация с двухфакторной защитой (Google Authenticator)
* **HTTPX** — асинхронные HTTP-клиенты для интеграции со сторонними сервисами (Google Translate Engine, MyMemory API)
* **In-Memory LRU/TTL Cache** — высокоскоростной кэш переводов (<1 мс на повторные фразы)
* **Sliding-Window Rate Limiter** — встроенная защита эндпоинтов авторизации и перевода от брутфорса и перегрузки
* **SSRF Defense** — валидация DNS и IP-адресов с блокировкой локальных и приватных подсетей при извлечении веб-страниц

### Frontend:
* **React 19** + **Vite** — быстрое одностраничное приложение (SPA)
* **Tailwind CSS** — строгий минималистичный дизайн (Monochrome Polar Ice) с поддержкой светлой и тёмной темы
* **Tesseract.js** — оптическое распознавание символов (OCR) прямо в браузере через WebAssembly
* **Web Speech API** — голосовой ввод и озвучивание диалогов (режим «Лицом к лицу»)
* **Axios** — HTTP-клиент с интерцепторами Bearer-токена
* **Keyboard Navigation** — поддержка глобальных горячих клавиш (`Ctrl+Enter`, `Ctrl+Shift+S`, `Esc`, `Ctrl+V`, `Ctrl+/`)
* **CSV Export** — экспорт персонального словаря в формате UTF-8 CSV для Excel, Numbers и Anki

## 📋 Основные функциональные возможности

1. **Многорежимный перевод:**
   * **Текст:** Быстрый перевод с умным автоопределением языка, переключением тональности (формальная/нейтральная), лимитом до 2000 символов и подсчётом знаков.
   * **Документы:** Чтение и извлечение текста из файлов `.txt`, `.md`, `.json`, `.csv`, `.pdf` прямо в браузере.
   * **Изображения (OCR / Google Lens):** Распознавание печатного текста с фото и сканов на стороне клиента без передачи графики на сервер. Поддержка вставки скриншотов из буфера обмена (`Ctrl + V`).
   * **Веб-страницы по URL:** Извлечение текста страницы по ссылке с защитой от SSRF.
   * **Диалог («Лицом к лицу»):** Сплит-режим для двух собеседников с поочерёдным вводом и голосовым синтезом.
2. **Персональный словарь и база знаний:**
   * Сохранение переведённых фраз в словарь в один клик.
   * Тематические категории с цветовой маркировкой.
   * Избранное, фильтрация по языковым парам и полнотекстовый поиск.
   * Режим карточек для заучивания слов (Flashcards).
   * Экспорт словаря в CSV-файл с кодировкой UTF-8 BOM.
3. **Безопасность и личный профиль:**
   * Регистрация с подтверждением email.
   * Двухфакторная аутентификация (2FA / TOTP) через Google Authenticator.
   * Смена пароля и сохранение индивидуальной темы оформления (Dark / Light) в БД.
   * Rate Limiting и блокировка приватных IP при веб-скрейпинге.

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
| :--- | :--- |
| `Ctrl + Enter` / `Cmd + Enter` | Мгновенный запуск перевода |
| `Ctrl + Shift + S` / `Cmd + Shift + S` | Поменять языки оригинала и перевода местами (Swap) |
| `Esc` | Закрыть любое открытое модальное окно или панель |
| `Ctrl + V` | Вставить изображение/скриншот из буфера обмена для OCR |
| `Ctrl + /` | Открыть справку по горячим клавишам |

## 🛠️ Локальный запуск проекта

### 1. Требования:
* Python 3.11+
* Node.js 18+
* PostgreSQL 15+ (или запущенный Docker)

### 2. Запуск Backend:
```bash
cd backend
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```
* Сервер доступен по адресу: `http://localhost:8000`
* Интерактивная документация Swagger UI: `http://localhost:8000/docs`

### 3. Запуск Frontend:
```bash
cd frontend
npm install
npm run dev
```
* Клиентское приложение откроется по адресу: `http://localhost:5173`
